# Components

This inventory describes application components currently present in the codebase.

| Component | Role | Purpose | Source |
| --- | --- | --- | --- |
| `RootLayout` | Server layout | Shared HTML/body shell, font variables, and page metadata | [app/layout.tsx](../app/layout.tsx) |
| `Home` | Server page | Next.js starter content at `/` | [app/page.tsx](../app/page.tsx) |

## RootLayout

- **Source:** [app/layout.tsx](../app/layout.tsx).
- **Inputs:** `children` through `LayoutProps<"/">`.
- **Behavior:** Wraps pages in English-language HTML and a flex-column body; applies Geist/Geist Mono font variables, full-height styling, and antialiasing.
- **Metadata:** Title `Create Next App`; description `Generated by create next app`.
- **Dependencies:** `next/font/google` and [app/globals.css](../app/globals.css).
- **Related components:** Wraps `Home` and any future pages. No authentication or data loading is implemented here.

## Home

- **Source:** [app/page.tsx](../app/page.tsx).
- **Route:** [`/`](routes.md#home).
- **Inputs:** None.
- **Behavior:** Displays the Next.js logo, starter editing instructions, and external links to templates, learning resources, deployment, and documentation. Styling includes light/dark variants.
- **Dependencies:** `Image` from `next/image`; `/next.svg` and `/vercel.svg` assets; global styling supplied through `RootLayout`.
- **Data and interactions:** Static content and links; no authentication, finance UI, IndexedDB staging, or sync behavior is implemented.

There are no separate application client components, entity forms, or sync components yet. Their intended responsibilities are described in [design.md](design.md#8-allowed-routes-and-home-components).
